## ✨ ویژگی‌های کلیدی (Features)

- ⚡ **پخش آنلاین روان با پلیر اختصاصی ExoPlayer**:
  - پشتیبانی از کیفیت‌های مختلف (480p, 720p, 1080p, 4K)
  - تصویر در تصویر (Picture-in-Picture / PiP)
  - کنترل ژست‌های لمسی (روشنایی، بلندی صدا، جابجایی زمان)
  - زیرنویس‌های چسبیده و فایل‌های صوتی دوبله اختصاصی
- 📥 **مدیر دانلود پیشرفته نیتیو (Download Manager)**:
  - دانلود پایدار در پس‌زمینه با Foreground Service
  - پشتیبانی از توقف و ادامه (Pause & Resume)
  - تعیین مسیر ذخیره‌سازی دلخواه (حافظه داخلی یا کارت حافظه)
  - دانلود همزمان و دانلود دسته‌ای (Batch Download) قسمت‌ها
- 📡 **موتورهای جستجو و پخش چندگانه**:
  - پشتیبانی از چندین سرور و پایگاه داده فعال
  - سیستم رادار هوشمند برای بررسی سلامت و پینگ لحظه‌ای سرویس‌ها
  - مدیریت خودکار و دور زدن اختلالات شبکه
- 🔔 **سیستم اعلان‌ها و اشتراک سریال‌ها**:
  - اعلان انتشار قسمت جدید برای سریال‌های مورد علاقه
  - پیام‌های اختصاصی و آدرس‌های جدید سرورها
- 🎨 **رابط کاربری مدرن و چشم‌نواز (Ultra-Modern Glassmorphism)**:
  - طراحی لوکس و تم دارک متناسب با چشم در محیط‌های تاریک
  - انیمیشن‌های روان و انتقال‌های بصری جذاب
  - فونت فارسی خوانا و زیبا (یکان‌بخ)
  - ویترین‌های داغ، برترین‌ها، تاریخچه و نشان‌شده‌ها

## 📱 نیازمندی‌های سیستم (Requirements)

- **حداقل اندروید:** Android 8.0 (API Level 26) یا بالاتر
- **معماری پردازنده:** سازگار با تمامی دستگاه‌های اندرویدی (Universal: `arm64-v8a`, `armeabi-v7a`, `x86`, `x86_64`)
- **اینترنت:** پایدار برای استریم آنلاین و ارتباط با سرورها

## 🚀 دانلود و نصب (Download & Install)

آخرین نسخه پایدار اپلیکیشن فیلیگرام را می‌توانید از بخش [**Releases**](https://github.com/milibots/filigram/releases) دانلود نمایید.

### اندروید (Android)

1. فایل `Filigram-Cinema-v1.0.0-Universal.apk` را دانلود کنید.
2. در صورتی که اخطار نصب برنامه‌ها از منابع ناشناس نمایش داده شد، مجوز مربوطه را تأیید کنید.
3. برنامه را نصب و اجرا نمایید!

### ویندوز (Windows)

1. فایل `Filigram-Cinema-<version>-Windows-Portable.exe` را دانلود کنید (بدون نصب اجرا می‌شود) یا نسخه نصبی `...-Windows-Setup.exe` را انتخاب کنید.
2. فایل را اجرا کنید؛ در صورت نمایش هشدار SmartScreen گزینه **More info → Run anyway** را بزنید.
3. برای پخش لینک‌هایی که کدک آن‌ها در ویندوز پشتیبانی نمی‌شود، از دکمه **VLC** داخل پلیر استفاده کنید.

## 🖥️ نسخه دسکتاپ ویندوز (Desktop App)

نسخه دسکتاپ با Electron نوشته شده و در پوشه [`desktop/`](desktop) قرار دارد.

- طراحی تیره و راست‌به‌چپ، هم‌سبک با نسخه اندروید
- انتخاب سیاره (منبع محتوا): مشتری، زحل، اورانوس، نپتون
- ویترین، فیلم‌ها، سریال‌ها، جستجو، کتابخانه و اعلان‌ها
- پلیر داخلی با ادامه تماشا، زیرنویس `srt`/`vtt`، کنترل سرعت و تمام‌صفحه

اجرای نسخه توسعه:

```bash
cd desktop
npm install
npm start
```

ساخت خروجی ویندوز:

```bash
cd desktop
npx electron-builder --win
```

> ساخت محلی روی ویندوز نیازمند فعال بودن **Developer Mode** است (برای ساخت symlink توسط electron-builder). در غیر این صورت از ورک‌فلوی گیت‌هاب (`.github/workflows/release.yml`) استفاده کنید.
